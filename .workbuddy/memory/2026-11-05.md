# 2026-11-05 工作日志

## 商机线索页搜索下拉被筛选按钮遮挡
- 文件：`src/pages/business-leads/index.vue`
- 原因：`.search-input-section` 的 `z-index: 20` 使其自身形成层叠上下文，内部 `.search-dropdown` 的 `z-index: 99` 无法越过父级层级，整块搜索区低于 `.lead-filter-row`（z-index: 40），下拉被「全部类型 / 登记时间」遮挡
- 修复：
  - `.search-input-section` 层级提到 `z-index: 50`
  - 两个浮层互斥：`toggleFilter` 时收起搜索联想（`showDropdown = false`）；点击搜索框 / 输入 / 点搜索时收起筛选面板（新增 `closeFilter`）
- 校验：`npx vue-tsc --noEmit` 通过

## 商机线索页「清空筛选」点击无反应
- 文件：`src/pages/business-leads/index.vue`
- 原因：`clearFilters()` 只重置线索类型/登记时间，未重置企业搜索条件（companyId / searchKeyword），且仅当类型或时间改变才重新请求；空态由企业搜索造成时点击等于无操作
- 修复：清空筛选改为重置全部条件（类型、时间、企业关键词、联想状态、定时器）并总是 `resetFeeds() + fetchList()`；加 `loading` 守卫避免请求被早退
- 空态按钮由 `<text>` 改为 `<view>` + `hover-class`，提升点击热区与反馈
- 校验：`npx vue-tsc --noEmit` 通过
